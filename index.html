SETUP WIZARD

FAQ

What is VeyraOS?

An independent, Debian-based Linux distribution project. Current builds are live images.

Is it based on Debian?

Yes, Debian 13 "trixie" per the README. It is not endorsed by Debian.

Do I need to build the ISO myself?

No. The Real PC and VM images are on GitHub Releases. Building is optional for contributors.

Is there an installer?

The Real PC release is described as a live version with no install. An installer is only a plan.

How do I verify an ISO?

Compute its SHA-256 locally and compare it with the checksum shown on the Downloads card, if one is listed.

PROJECT / ABOUT
About VeyraOS


A Debian-based live Linux with a red V, a dark XFCE desktop and its own command line tool, veyra. Boot from USB, use it, shut down, and your disks are untouched. The kernel, package manager and nearly all software come from Debian.
It is experimental: not every hardware configuration has been tested. Created by Daniel.veyra, MIT licensed.
