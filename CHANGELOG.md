# Changelog

## 0.3 (experimental, unreleased)

First version with a reproducible build system.

- live-build based ISO build (`build.sh`) for Debian 13 "trixie", amd64
- XFCE desktop with Veyra-Dark and Veyra-Light themes, red accent, own wallpaper and panel layout
- generated xfwm4 window decorations
- red V logo as SVG, PNG and monochrome variants
- `veyra` command line tool with 14 commands
- shell prompt, banner and aliases
- identity files: `/usr/lib/os-release`, `/etc/veyra-release`, `/etc/issue`
- automated tests, ISO verification script, VM boot test
- No installer. Live session only.

The ISO has not been built or booted yet. See README, "Status".
